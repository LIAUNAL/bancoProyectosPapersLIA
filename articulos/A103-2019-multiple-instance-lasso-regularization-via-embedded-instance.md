# Multiple-instance lasso regularization via embedded instance selection for emotion recognition

**Autores:** Julián Caicedo-Acosta, David  Augusto Cardenas Peña, Diego Fabián Collazos-Huertas, Jorge Iván Padilla Buriticá, G. Castaño-Duque, German Castellanos-Dominguez  
**Revista:** Lecture notes in computer science (2019)  
**DOI:** https://doi.org/10.1007/978-3-030-19591-5_25  
**Temas:** T01 Interfaces cerebro-computador y decodificación EEG  
**Clúster:** C04 EEG, TDAH y soporte diagnóstico

## Aplicación
Reconocimiento de emociones por EEG con la base DEAP.

## Problema de investigación
La no estacionariedad del EEG complica el análisis temporal de emociones.

## Propuesta o novedad
Se propone MILRES, aprendizaje de múltiples instancias con regularización LASSO y selección embebida de instancias.

## Resultados
MILRES supera otros enfoques de reconocimiento de emoción basados en EEG del estado del arte.

## Conclusiones principales
Selección embebida de instancias mejora el reconocimiento de emoción.

## Métodos
- aprendizaje de múltiples instancias
- LASSO
- selección de instancias

## Idea para trabajo futuro
Probar MILRES en otros conjuntos de emociones y con señales periféricas fusionadas.

<details><summary>Abstract</summary>

This work proposes a temporal analysis approach, termed MILRES, based on the Multi-Instance Learning framework that includes a multiple instance Regularization with LASSO penalty and an Embedded instance Selection that outperforms other EEG-based emotion recognition approaches from the state-of-the-art.
