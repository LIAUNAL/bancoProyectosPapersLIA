# Enhanced Spatio-Temporal Resolution using Dynamic Sparse Coding for EEG Inverse Problem Solutions.

**Autores:** JUAN DAVID MARTINEZ VARGAS, EDUARDO GIRALDO SUAREZ, CESAR GERMAN CASTELLANOS DOMINGUEZ  
**Revista:** IAENG INTERNATIONAL JOURNAL OF COMPUTER SCIENCE (2019)  
**DOI:** No disponible  
**Temas:** T02 Conectividad cerebral e imagen de fuentes neuronales  
**Clúster:** C03 Conectividad cerebral e imagen de fuentes

## Aplicación
Reconstrucción de actividad neuronal a partir de EEG (problema inverso).

## Problema de investigación
El problema inverso en EEG sufre de baja resolución espacio-temporal.

## Propuesta o novedad
A partir del título, se propone codificación dispersa dinámica (DSC) para mejorar la resolución espacio-temporal de las soluciones del problema inverso de EEG. Al no haber abstract, los detalles son generales.

## Resultados
No se dispone de resultados explícitos al no contar con abstract.

## Conclusiones principales
La propuesta busca mejorar la resolución de las soluciones inversas mediante restricciones dinámicas.

## Métodos
- codificación dispersa dinámica
- problema inverso

## Idea para trabajo futuro
Comparar sistemáticamente DSC frente a otras restricciones espacio-temporales en datos clínicos reales.
