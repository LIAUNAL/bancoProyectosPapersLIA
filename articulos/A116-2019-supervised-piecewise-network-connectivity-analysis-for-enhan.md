# Supervised piecewise network connectivity analysis for enhanced confidence of auditory oddball tasks

**Autores:** Jorge Iván Padilla Buriticá, Juana Valeria Hurtado, German Castellanos-Dominguez  
**Revista:** Biomedical Signal Processing and Control (2019)  
**DOI:** https://doi.org/10.1016/j.bspc.2019.04.020  
**Temas:** T02 Conectividad cerebral e imagen de fuentes neuronales  
**Clúster:** C03 Conectividad cerebral e imagen de fuentes

## Aplicación
Análisis de conectividad en EEG de tareas auditivas oddball.

## Problema de investigación
La conectividad cerebral en tareas oddball es difícil de resumir de forma consistente y de discriminar entre estímulos.

## Propuesta o novedad
Se propone un análisis de conectividad por tramos usando el índice de sincronización de fase (PLI), con un procedimiento de combinación en un valor único de relevancia y un umbral estadístico supervisado que reduce la matriz de conectividad conservando los enlaces más discriminantes.

## Resultados
En una tarea auditiva oddball, el análisis produce un conjunto de nodos relevante para ondas delta y theta, más coherente y con grafos de grupo más consistentes.

## Conclusiones principales
El enfoque supervisado mejora la consistencia de la conectividad a nivel de grupo.

## Métodos
- índice de sincronización de fase
- análisis de relevancia
- umbralización estadística

## Idea para trabajo futuro
Evaluar si el conjunto de nodos relevantes sirve como biomarcador en poblaciones clínicas.

<details><summary>Abstract</summary>

Abstract We present a network connectivity analysis to assess a relevant vector, valuing the contribution of connection node sets in distinguishing between labeled response stimuli. To this end, the piecewise computation of Phase Locking Index is performed, suggesting a combination procedure to reflect the whole recording span with a single relevance value. Further, we use a supervised, statistical thresholding algorithm to reduce the connectivity matrix dimension, holding the links that mostly differentiate the brain responses to each evoked stimulus. Obtained results in an auditory oddball task show that the developed analysis yields a relevant node set for δ and θ waves that becomes more coherent, connected with improved consistency of performed group-level connectivity graphs.
