# A data representation approach to support imbalanced data classification based on TWSVM

**Autores:** C. Jimenez, Andrés Marino Álvarez-Meza, Alvaro Angel Orozco  
**Revista:** Lecture notes in computer science (2019)  
**DOI:** https://doi.org/10.1007/978-3-030-13469-3_7  
**Temas:** T05 Métodos kernel y aprendizaje basado en teoría de la información  
**Clúster:** C10 Visión por computador y representación kernel

## Aplicación
Clasificación de datos desbalanceados con máquinas de vectores de soporte gemelas.

## Problema de investigación
El desbalance de clases limita el desempeño de clasificadores como TWSVM.

## Propuesta o novedad
Se propone una versión mejorada de TWSVM con una formulación dual extendida de su programa cuadrático que representa las muestras en un espacio de alta dimensión (con alineamiento de kernel centrado).

## Resultados
Se reformula la forma dual de TWSVM para representar muestras de entrada; no se reportan cifras en el resumen.

## Conclusiones principales
La reformulación dual da una representación útil para tareas desbalanceadas.

## Métodos
- TWSVM
- CKA
- programación cuadrática

## Idea para trabajo futuro
Combinar la formulación con aprendizaje sensible al costo para desbalances extremos.
