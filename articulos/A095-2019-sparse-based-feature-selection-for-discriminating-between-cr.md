# Sparse-based feature selection for discriminating between crops and weeds using field images

**Autores:** Daniel Guillermo García-Murillo, Andrés Marino Álvarez-Meza, David  Augusto Cardenas Peña, William Hincapie-Restrepo, German Castellanos-Dominguez  
**Revista:** Lecture notes in computer science (2019)  
**DOI:** https://doi.org/10.1007/978-3-030-33904-3_33  
**Temas:** T10 Agricultura de precisión, ambiente y teledetección; T08 Visión por computador y análisis de video  
**Clúster:** C10 Visión por computador y representación kernel

## Aplicación
Discriminación entre cultivos y malezas en fotografías de campo para agricultura de precisión.

## Problema de investigación
El ruido en rasgos reduce la clasificación y la interpretabilidad en discriminación cultivo/maleza.

## Propuesta o novedad
Se introduce selección de rasgos esparsa con el operador Lasso para eliminar rasgos ruidosos.

## Resultados
Se mejora la clasificación y se obtiene interpretabilidad de rasgos.

## Conclusiones principales
Lasso es útil para discriminar cultivos de malezas.

## Métodos
- LASSO
- selección de rasgos

## Idea para trabajo futuro
Validar con imágenes de dron en diferentes etapas fenológicas.
