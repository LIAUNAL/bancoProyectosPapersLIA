# EEG Channel Relevance Analysis Using Maximum Mean Discrepancy on BCI Systems

**Autores:** David Luna-Naranjo, Juana Valeria Hurtado-Rincón, David  Augusto Cardenas Peña, V. H. Castro, Héctor Fabio Torres-Cardona, German Castellanos-Dominguez  
**Revista:** Lecture notes in computer science (2019)  
**DOI:** https://doi.org/10.1007/978-3-030-13469-3_95  
**Temas:** T01 Interfaces cerebro-computador y decodificación EEG; T05 Métodos kernel y aprendizaje basado en teoría de la información  
**Clúster:** C02 BCI por imaginación motora

## Aplicación
Selección de canales EEG en sistemas BCI de imaginación motora.

## Problema de investigación
Reducir canales sin perder desempeño.

## Propuesta o novedad
Se propone rMMD, análisis de relevancia con discrepancia media máxima entre pares de ensayos de un canal.

## Resultados
rMMD mejora estadísticamente la clasificación con un conjunto reducido de canales.

## Conclusiones principales
MMD es un criterio eficaz para ordenar canales.

## Métodos
- MMD
- ranking de canales

## Idea para trabajo futuro
Aplicar rMMD en línea para adaptar el conjunto de canales a cada sesión.

A relevance analysis based on the maximum mean discrepancy as the distance function between a pair of single-channel trials, termed rMMD, which statistically improves the classification of MI tasks with a reduced set of channels.
