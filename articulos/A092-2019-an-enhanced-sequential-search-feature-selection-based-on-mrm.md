# An Enhanced Sequential Search Feature Selection Based on mRMR to Support FCD Localization

**Autores:** J. Castañeda-Gonzalez, Andrés Marino Álvarez-Meza, Alvaro Angel Orozco  
**Revista:** Lecture notes in computer science (2019)  
**DOI:** https://doi.org/10.1007/978-3-030-13469-3_57  
**Temas:** T03 Imagen médica y neuroimagen; T05 Métodos kernel y aprendizaje basado en teoría de la información  
**Clúster:** C10 Visión por computador y representación kernel

## Aplicación
Localización de displasia cortical focal (FCD) en imágenes cerebrales.

## Problema de investigación
El desbalance entre regiones displásicas y sanas dificulta la localización y la selección de rasgos.

## Propuesta o novedad
Se propone una selección secuencial de rasgos basada en mRMR con función de costo de información mutua para manejar el desbalance.

## Resultados
El resumen presenta el enfoque de procesamiento de imagen para apoyar la localización FCD, sin cifras.

## Conclusiones principales
mRMR secuencial aporta rasgos relevantes para localizar FCD.

## Métodos
- mRMR
- información mutua
- búsqueda secuencial

## Idea para trabajo futuro
Validar la selección de rasgos en cohortes multicéntricas de epilepsia.

<details><summary>Abstract</summary>

This work proposes a new image processing approach to support FCD localization using a minimal redundancy maximal relevance-based feature selection stage that relies on a mutual information cost function to deal with imbalance problems.
